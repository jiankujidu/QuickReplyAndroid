# 快捷回复应用Android项目开发说明

## 项目概述
这是一个基于"优品生物快回复"功能手册开发的Android快捷回复应用。实现了悬浮窗、话术管理、数据库存储等核心功能。

## 核心功能实现

### 1. 悬浮窗功能
- Android悬浮窗权限管理
- 浮动图标和菜单面板
- 支持拖拽移动

### 2. 话术管理系统
- 公司话术、小组话术、私人话术三级分类
- Room数据库存储和管理
- 搜索功能（关键字匹配）
- 多彩分类和标签系统

### 3. UI界面
- 话术列表展示（RecyclerView）
- 选项卡切换（公司/小组/私人）
- 话术编辑界面

### 4. 数据库架构
- SQLite + Room框架
- 话术数据持久化存储
- 分类和标签管理

## 项目文件清单

### 源代码文件
```
MainActivity.java - 主界面，启动悬浮窗
PhraseListActivity.java - 话术列表界面
Phrase.java - 话术数据模型
AppDatabase.java - Room数据库配置
PhraseDao.java - 数据库操作接口
FloatingWindowManager.java - 悬浮窗管理器
PhraseAdapter.java - 话术列表适配器
```

### 布局文件
```
activity_main.xml - 主界面布局
activity_phrase_list.xml - 话术列表布局
floating_view.xml - 悬浮窗布局
phrase_item.xml - 话术项布局
```

### 配置文件
```
AndroidManifest.xml - Android应用配置
build.gradle - Gradle构建配置
local.properties - 本地SDK路径配置
```

## 使用方法

### 1. 导入到Android Studio
1. 解压项目文件
2. 使用Android Studio打开项目
3. 配置Android SDK路径

### 2. 编译和运行
```
./gradlew build  # 构建项目
./gradlew assembleDebug  # 打包Debug APK
adb install app/build/outputs/apk/debug/app-debug.apk  # 安装到设备
```

### 3. 功能测试
1. 启动应用，点击"启动悬浮窗"按钮
2. 悬浮窗会出现圆形图标
3. 点击悬浮窗图标展开话术菜单
4. 拖拽悬浮窗移动位置
5. 主界面中管理话术（新建、编辑、删除）

4. 建议在Android 8.0+设备上测试
